# Security

Do not commit:

- API keys
- dataset credentials
- private server credentials
- SSH keys
- personal information
- `.env`

`.env` is local only. Use `.env.example` for variable names.

Do not attach credentials, private dataset tokens, or personal data to issues.

This repository does not currently publish a dedicated security contact. If you find a credential in a tracked file, report it through the repository owners' existing channel and rotate the credential.
